# Resolution File Manager 13.1.4

Version 13.1.4

- New automatic variable bitrate (VBR) compression can produce significantly smaller video conversions while maintaining good visual quality. Results depend on the source and chosen settings.
- Max Quality encoding and adjustable audio bitrate, with 192 kb/s as standard and 128 kb/s available.
- Keep source H.265 MKV is the first-use preset; conversion choices are remembered.
- Minimise and restore image/video conversion windows while continuing to work in RFM.
- Clearer ticked-file controls, folder counts and prompts when ticked and highlighted files differ.
- Long filenames show both ends, with full source/output paths and an output summary before starting.
- Live encoder, speed, estimated remaining time and automatic fallback information.
