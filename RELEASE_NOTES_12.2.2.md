# Resolution File Manager 12.2.2 for Windows

Resolution File Manager is a portable, dual-pane tool for reviewing, sorting, comparing, organising and converting large image and video collections. It combines Explorer-style navigation with technical media information, cached thumbnails, independent previews, duplicate review and reversible file-management workflows.

Highlights include recursive scanning, codec/resolution/bitrate columns, configurable sorting and filters, two preview panes, fast cached thumbnails, integrity checking, similarity review, batch rename, folder rules, inventory reports and hardware-aware FFmpeg conversion.

Version 12.2.2 adds an entirely optional Buy Me a Coffee link under Help and About. The application does not open the link automatically and does not handle payment information.

This release is portable and bundles the media tools it needs. Extract the ZIP and run the versioned executable. See `WINDOWS_RELEASE.md`, `PRIVACY.md`, and `THIRD_PARTY_NOTICES.md` before redistribution.
