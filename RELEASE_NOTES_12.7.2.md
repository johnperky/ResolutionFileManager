# 12.7.2 — selection and ticks separated (English review)

- Mouse rectangle/range selection changes highlighting only, never persistent ticks.
- Tick selection, Untick selection and Clear ticks beside Sort and Select all shown in an independent top row. Opening Info cannot squeeze those controls. Same tick commands in file/background context menus. Add or remove highlighted paths only.
- Compact 180-pixel Info starting width; reset oversized legacy review widths once, then retain new user widths.
- Deep folder tree automatically shifts indentation left to make the selected folder visible; horizontal scrollbar retains access to ancestors.
- Ctrl-drag adds highlights, independently of ticks.
- Outline-only selection rectangle leaves file contents visible. Drag events continue across thumbnail children and across pane boundaries; release ends the gesture reliably.
- Checkbox targets are restricted to the visible glyph, and toggle on release rather than press. Dragging near or from a checkbox creates a highlight selection without changing ticks.
- Thumbnail slider appears only in Thumbnails, with its size remembered while Details is active.
- Previous English review features retained. Not a multilingual or public release.
