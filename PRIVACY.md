# Privacy

Resolution File Manager is a local desktop application. It does not require an account, display advertising, contain analytics, upload a media library, or send filenames and metadata to the developer.

The application reads folders selected by the user and stores settings, cached metadata, thumbnails, ratings, labels, and tags locally on the computer. File operations and media conversions are performed locally.

The application accesses the internet only when the user explicitly opens an external link, such as the optional Buy Me a Coffee page. Payment information is handled by the external website and is never received by Resolution File Manager.

Windows, security software, package managers, browsers, and download services may independently collect information according to their own policies.

Privacy statement version: 30 September 2026.
