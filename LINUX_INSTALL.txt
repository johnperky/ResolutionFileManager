RESOLUTION FILE MANAGER — LINUX 12.7.11 REVIEW CANDIDATE

Target: x86_64 Linux Mint 22.x / Ubuntu 24.04. Built on Ubuntu 24.04
(glibc 2.39). Older Mint versions are not supported by this candidate.
Windows remains the separately published 12.7.10 release.

For the prebuilt review download, extract the .tar.gz, open its folder and run
"Run Resolution File Manager.sh". It preserves the exact reviewed binary.
Install runtime/media/font support on Mint if needed:
  sudo apt update
  sudo apt install ffmpeg python3-tk fonts-noto-core fonts-noto-cjk

Linux text sizes are 100%, 125%, 150% and 175%; 200% has been removed on Linux.
An older saved 200% preference returns to 100%. Windows keeps its existing sizes.

Verified in Ubuntu 24.04/WSL with Xvfb: 89 unit tests (2 Windows-only skips),
43-language real-Tk scan/Help/navigation checks, hidden-files and Appearance
regressions, packaged Arabic startup, and exact embedded source/43 locales.
These checks do not establish full physical Mint compatibility.
On your Mint computer test startup, image/video preview and sound, resize at
100/125/150/175%, hidden-files toggle, Help, external drag/drop and desktop Trash
using disposable media. Report failures before treating this candidate as stable.

BUILDING FROM SOURCE

Use the complete versioned source archive, including
localization.py, reminder_policy.py, verify_release_assets.py, locales and docs/help.
The old 12.3.0 handoff remains a historical snapshot and will still build 12.3.0.
Read VERSION.txt in the new handoff before building.

Linux Mint/Ubuntu build requirements:
  sudo apt update
  sudo apt install python3 python3-pip python3-venv python3-tk ffmpeg fonts-noto-core fonts-noto-cjk

From the copied source directory:
  sh build_linux.sh

The builder uses an isolated .venv-linux-build environment, never sudo pip or
--break-system-packages. It checks all locale/help resources before packaging.
The output path printed at completion includes VERSION.txt and architecture.
Use chmod +x on that file after copying to a compatible Linux PC, then run it.

A PyInstaller one-file build still needs compatible glibc/system libraries and
a graphics/audio session. Build on the oldest target Mint baseline and test
each intended architecture. FFmpeg may require system shared libraries even
when its executable is bundled. Hardware encoding depends on installed drivers.
Windows Explorer reveal uses xdg-open on Linux; Trash support depends on a
working desktop trash implementation. Audio and external drag/drop require a
real desktop session and are not proven by headless tests.

For source development, install requirements.txt into a private virtualenv,
activate it and run sh run_linux.sh. See DEVELOPMENT_WORKFLOW.md for exporting
complete handoffs and preserving earlier release versions.
