# Resolution File Manager release status

Windows 13.1.4 reuses the user-approved Store executable. Included changes: automatic VBR compression, enhancement/audio options, conversion window and selection improvements, and visually similar image review across subfolders.

Exact source and package hashes are included with the release. Focused English/native and short CPU/NVIDIA checks were reused; no new clean-OS or broad language suite is claimed. Linux and macOS work remain separate.
