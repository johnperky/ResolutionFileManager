# Microsoft Store 掲載情報 — 日本語（日本）

## 製品名

Resolution File Manager

## 短い説明

大量の動画と画像をすばやくスキャン、プレビュー、並べ替え、整理、変換できます。

## 説明

Resolution File Manager は、大量の動画や画像を扱うために設計された高機能な2ペイン式メディアファイルマネージャーです。

1つのフォルダーまたはサブフォルダーを含むツリー全体をスキャンし、数千件のファイルをコーデック、解像度、サイズ、再生時間、フレームレート、ビットレート、日付、種類、評価、ラベル、タグで並べ替え、絞り込めます。動画をすばやくプレビューし、ファイルを左右に並べて比較し、重複を確認しながら、現在位置を失わずに選択項目を整理できます。

選択した動画を H.264、H.265、AV1 に変換したり、プロキシを作成したり、互換性のあるファイルを再エンコードせずにリマックスしたりできます。対応しているハードウェアアクセラレーションも選択できます。メタデータとサムネイルのキャッシュにより再表示が高速になり、バックグラウンドスキャンと調整可能なパフォーマンス設定により、大規模なライブラリでも操作性を保ちます。

すべての処理はPC内で行われます。アカウントは不要で、広告や分析機能はなく、ファイル名、メタデータ、画像、動画が開発者へアップロードされることもありません。アプリの画面表示は現在英語です。

## 主な機能

- 独立したプレビューとフォルダー履歴を備えた2ペイン式ファイル閲覧
- サブフォルダーを含む再帰スキャンと選択
- コーデック、解像度、サイズ、再生時間、ビットレート、FPSなどで並べ替えと絞り込み
- 高速な動画シーク、可変再生速度、フレーム書き出し
- サムネイルと技術的なメディア情報のキャッシュ
- コピー、移動、名前変更、ごみ箱への削除と元に戻せるワークフロー
- 重複ファイルの視覚的な確認と左右比較
- 一括名前変更、フォルダールール、スマートコレクション、評価、ラベル、タグ
- ハードウェアアクセラレーションを選べる H.264、H.265、AV1 変換
- 整合性チェック、コンタクトシート、CSV/JSON/HTML 一覧レポート
- アカウント、広告、分析機能のないローカル処理

## 新機能

バージョン 12.3.0 では、両方のペインに独立したチェックボックス操作グループを追加しました。並べ替えや絞り込みをまたいでファイルを集めながら、別のメディアを選択してプレビューできます。集めたチェック済みファイル全体に、ファイル管理、分析、変換の操作を適用できます。
