# Microsoft Store listing — English (India)

## Product name

Resolution File Manager

## Short description

Quickly scan, preview, sort, organise and convert large video and image collections.

## Description

Resolution File Manager is a powerful dual-pane media manager built for large collections of videos and images.

Scan a folder or a complete subfolder tree, then sort and filter thousands of files by codec, resolution, size, duration, frame rate, bitrate, date, type, rating, label or tag. Quickly move through video previews, compare files side by side, review duplicates and organise selected items without losing your place.

Convert selected videos to H.264, H.265 or AV1, create proxies, remux compatible files and choose supported hardware acceleration. Cached metadata and thumbnails make repeat visits faster, while background scanning and adjustable performance profiles help the interface remain responsive with large libraries.

Everything runs locally. The app does not require an account, contain advertising or analytics, or upload filenames, metadata, images or videos to the developer.

## Features

- Dual-pane file browsing with independent previews and folder histories
- Recursive scanning and selection across subfolders
- Sort and filter by codec, resolution, size, duration, bitrate, FPS and more
- Fast video scrubbing, variable playback speeds and frame export
- Cached thumbnails and technical media metadata
- Copy, move, rename and Recycle Bin deletion with reversible workflows
- Visual duplicate review and side-by-side comparison
- Batch rename, folder rules, smart collections, ratings, labels and tags
- H.264, H.265 and AV1 conversion with selectable hardware acceleration
- Integrity checking, contact sheets and CSV/JSON/HTML inventory reports
- Local processing with no account, advertising or analytics

## What's new

Version 12.3.0 adds independent tick-box action groups in both panes. Collect files across sorting and filtering while continuing to highlight and preview other media, then apply file-management, analysis or conversion actions to the complete ticked group.
