# Microsoft Store 등록 정보 — 한국어(대한민국)

## 제품 이름

Resolution File Manager

## 간단한 설명

대규모 동영상 및 이미지 모음을 빠르게 검색, 미리 보기, 정렬, 관리 및 변환하세요.

## 설명

Resolution File Manager는 대규모 동영상 및 이미지 모음을 위해 설계된 강력한 이중 창 미디어 파일 관리자입니다.

폴더 하나 또는 전체 하위 폴더 트리를 검색한 다음 수천 개의 파일을 코덱, 해상도, 크기, 재생 시간, 프레임 속도, 비트 전송률, 날짜, 형식, 평점, 레이블 또는 태그별로 정렬하고 필터링할 수 있습니다. 동영상을 빠르게 미리 보고, 파일을 나란히 비교하고, 중복 파일을 검토하며, 현재 위치를 잃지 않고 선택한 항목을 정리할 수 있습니다.

선택한 동영상을 H.264, H.265 또는 AV1으로 변환하고, 프록시를 만들고, 호환 파일을 재인코딩 없이 리먹싱하고, 지원되는 하드웨어 가속을 선택할 수 있습니다. 캐시된 메타데이터와 미리보기 이미지는 다시 방문할 때 속도를 높이며, 백그라운드 검색과 조정 가능한 성능 프로필은 대규모 라이브러리에서도 인터페이스 반응성을 유지하는 데 도움이 됩니다.

모든 처리는 로컬에서 실행됩니다. 계정이 필요하지 않고 광고나 분석 기능이 없으며, 파일 이름, 메타데이터, 이미지 또는 동영상을 개발자에게 업로드하지 않습니다. 앱 인터페이스는 현재 영어로 제공됩니다.

## 기능

- 독립적인 미리 보기와 폴더 기록을 제공하는 이중 창 파일 탐색
- 하위 폴더 전체의 재귀 검색 및 선택
- 코덱, 해상도, 크기, 재생 시간, 비트 전송률, FPS 등으로 정렬 및 필터링
- 빠른 동영상 탐색, 가변 재생 속도 및 프레임 내보내기
- 캐시된 미리보기 이미지와 기술 미디어 메타데이터
- 복사, 이동, 이름 변경 및 휴지통 삭제와 되돌릴 수 있는 작업 흐름
- 시각적 중복 검토 및 나란히 비교
- 일괄 이름 변경, 폴더 규칙, 스마트 컬렉션, 평점, 레이블 및 태그
- 선택 가능한 하드웨어 가속을 사용하는 H.264, H.265 및 AV1 변환
- 무결성 검사, 콘택트 시트 및 CSV/JSON/HTML 인벤토리 보고서
- 계정, 광고 또는 분석 기능이 없는 로컬 처리

## 새로운 기능

버전 12.3.0에서는 양쪽 창에 독립적인 체크박스 작업 그룹을 추가했습니다. 정렬 및 필터링 중에도 파일을 계속 모으고 다른 미디어를 선택하여 미리 볼 수 있으며, 체크된 전체 그룹에 파일 관리, 분석 또는 변환 작업을 적용할 수 있습니다.
