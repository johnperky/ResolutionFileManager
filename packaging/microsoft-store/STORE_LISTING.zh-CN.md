# Microsoft Store 商店信息 — 简体中文（中国）

## 产品名称

Resolution File Manager

## 简短说明

快速扫描、预览、排序、整理和转换大型视频与图片库。

## 说明

Resolution File Manager 是一款功能强大的双窗格媒体文件管理器，专为大型视频和图片库而设计。

您可以扫描单个文件夹或完整的子文件夹树，并按编解码器、分辨率、大小、时长、帧率、比特率、日期、类型、评级、标签或标记对数千个文件进行排序和筛选。快速浏览视频预览、并排比较文件、检查重复文件，并在整理所选项目时保持当前位置。

您可以将所选视频转换为 H.264、H.265 或 AV1，创建代理文件，对兼容文件进行无重新编码封装，并选择受支持的硬件加速方式。缓存的元数据和缩略图可加快再次访问速度；后台扫描和可调节的性能配置有助于在处理大型媒体库时保持界面响应。

所有处理都在本地完成。本应用无需账户，不含广告或分析功能，也不会向开发者上传文件名、元数据、图片或视频。应用界面目前为英文。

## 功能

- 双窗格文件浏览，每个窗格都有独立预览和文件夹历史记录
- 跨子文件夹递归扫描和选择
- 按编解码器、分辨率、大小、时长、比特率、FPS 等排序和筛选
- 快速视频拖动预览、可变播放速度和画面导出
- 缓存缩略图和技术媒体元数据
- 复制、移动、重命名和移入回收站，并支持可撤销工作流程
- 可视化重复文件检查和并排比较
- 批量重命名、文件夹规则、智能集合、评级、标签和标记
- H.264、H.265 和 AV1 转换，并可选择硬件加速
- 完整性检查、联系表以及 CSV/JSON/HTML 清单报告
- 本地处理，无需账户，不含广告或分析功能

## 新增功能

版本 12.3.0 在两个窗格中加入了独立的复选框操作组。您可以在排序和筛选过程中持续收集文件，同时继续高亮和预览其他媒体，然后对完整的已勾选文件组执行文件管理、分析或转换操作。
