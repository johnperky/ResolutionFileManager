## Product name

Resolution File Manager

## Short description

Rapidly scan, preview, sort, organise and convert large video and image collections.

## Description

Resolution File Manager is a powerful dual-pane media manager built for large collections of videos and images.

Scan a folder or an entire subfolder tree, then sort and filter thousands of files by codec, resolution, size, duration, frame rate, bitrate, date, type, rating, label or tag. Quickly move through video previews, compare files side by side, review duplicates and organise selected items without losing your place.

Convert selected videos to H.264, H.265 or AV1, create proxies, remux compatible files and choose supported hardware acceleration. Cached metadata and thumbnails make repeat visits faster, while background scanning and adjustable performance profiles help the interface remain responsive on large libraries.

Everything runs locally. The app does not require an account, contain advertising or analytics, or upload filenames, metadata, images or videos to the developer.

## Features

- Dual-pane file browsing with independent previews and folder histories
- Recursive scanning and selection across subfolders
- Sort and filter by codec, resolution, size, duration, bitrate, FPS and more
- Fast video scrubbing, variable playback speeds and frame export
- Cached thumbnails and technical media metadata
- Copy, move, rename and Recycle Bin deletion with reversible workflows
- Visual duplicate review and side-by-side comparison
- Batch rename, folder rules, smart collections, ratings, labels and tags
- H.264, H.265 and AV1 conversion with selectable hardware acceleration
- Integrity checking, contact sheets and CSV/JSON/HTML inventory reports
- Local processing with no account, advertising or analytics

## Certification notes

Resolution File Manager is a conventional full-trust desktop file manager. It reads only folders chosen by the user. Copy, move, rename, Recycle Bin deletion, conversion and report creation occur only after direct user action. It bundles FFmpeg/ffprobe/ffplay for local media inspection, preview and conversion. It does not require elevation, install services or drivers, modify protected system locations, or transmit the user's media library.

The optional Buy Me a Coffee link appears only in Help/About and opens the system web browser after the user selects it. No purchase occurs in the app.
