# Resolution File Manager 12.7.11 — Linux

- Updates Linux with the current 43-language interface and Help, hidden-files Tools toggle, transfer/Undo improvements and reviewed Info/conversion layout corrections.
- Wraps top toolbar actions when enlarged Linux fonts exceed the available window width. Restoring normal text size restores the compact layout; media behaviour is unchanged.
- Linux offers 100%, 125%, 150% and 175% text size; the problematic 200% option is removed. Older saved 200% settings return to 100%. Windows retains its existing choices and translated button names are preserved.
- Targets x86_64 Linux Mint22.x / Ubuntu24.04. Built and tested on Ubuntu24.04 under WSL; physical Mint desktop, audio, desktop drag/drop, Trash and hardware encoding remain separate checks.
- Noto core/CJK fonts provide coverage for the translated interface. The accompanying Linux README records system requirements and exact verification scope.

The published Windows build remains12.7.10; this Linux update does not replace its verified files or submit anything to Microsoft Store.
