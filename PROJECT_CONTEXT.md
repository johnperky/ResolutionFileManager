Version 10.0 begins the performance-focused architecture upgrade by replacing the monolithic JSON metadata cache with an indexed SQLite database. Existing version-9 cache records migrate automatically once and remain available as a legacy backup. Cache hits use indexed path/size/date lookups, new results are written incrementally in batches of 250, and prune/clear operations work directly against the database instead of copying and rewriting the entire cache in memory.

Version 10.1 accelerates exact duplicate searches with a staged hashing pipeline. Same-size candidates first receive a small BLAKE2 fingerprint sampled from the beginning, middle, and end; only matching fingerprints proceed to whole-file SHA-256 verification. Quick and full hashes are stored in SQLite against path, size, and modification time, so unchanged files are not reread on later searches. Status text distinguishes quick checking, exact verification, and reused fingerprints; the existing review-only safety workflow remains unchanged.

Version 10.3 introduces a central workload controller and reversible Quiet, Balanced, and Fast profiles under Tools > Cache and scanning.
