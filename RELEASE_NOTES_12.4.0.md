# Resolution File Manager 12.4.0

Version 12.4.0 adds automatic interface-language detection and bundled English, Simplified Chinese, Dutch, French, German, Japanese, Korean, Russian and Spanish language packs. Choose **Tools > Language** to override the operating-system language or return to System default; restart the application after changing it. Missing translations safely fall back to English.

The searchable Help Centre now follows the selected language. The main window, every menu and submenu, pane selectors, column headings, scan/status text, preview and inspector controls, conversion window, duplicate checker, language controls, reminders, and standard information/warning/error/confirmation dialogs are translated. Technical codec and hardware-engine names, paths and user-authored tags remain unchanged.

This version also adds two optional local reminders. A Microsoft Store rating invitation can first appear after five successful launches across at least three distinct days; choosing Later postpones it for ten launches. An optional Buy Me a Coffee invitation begins at launch 11 and, after Maybe later, can recur every 11 launches. Either reminder can be permanently disabled or re-enabled under **Tools > Reminders**. Only one reminder is shown during a launch, with the Store rating invitation taking priority.

Launch counts, dates and preferences stay in the local settings file. The application does not upload usage information, detect whether a rating or donation was completed, or open either destination without an explicit button press.

Version 12.3.0 remains the rollback executable.
